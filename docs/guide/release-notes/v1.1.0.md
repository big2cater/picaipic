# Release Notes - PicAiPic v1.1.0

PicAiPic v1.1.0 advances the local-first Windows/Linux photo manager with smoother large-library browsing, faster repeat scans, richer built-in tools, and tighter AI plugin lifecycle behavior. A private draft release may exist while final regression work continues; publication remains an owner decision.

## Large-Library Performance

- Cancel stale thumbnail work after scrollbar jumps and library/viewport changes.
- Deduplicate overlapping metadata chunks and thumbnail IPC requests.
- Lazy-mount per-thumbnail context menus and avoid unnecessary per-card plugin/status loads.
- Use contained `translate3d` virtual item positioning and narrower resize observation to reduce scroll-time layout work.
- Cache folder ids and lightweight file state for one scan, then batch unchanged-file timestamps in bounded transactions.
- On the representative 10,343-file unchanged library, the accepted 500-item write window reduced transactions from 207 to 21 and total rescan time from 10.164s to 8.786s.

## Local AI and Search

- Batch vision embeddings with transaction writes and bounded next-batch decode/preprocess overlap.
- Keep exact matrix search as the default for large libraries; HNSW remains explicit diagnostic opt-in.
- Validate 110,343-vector startup warm in 2.876s with a 216.8 MiB matrix and 0.00% post-settle CPU in the measured run.
- Improve JPEG metadata fast paths and content-sniffing fallbacks while preserving incomplete/candidate recovery behavior.

## Built-In Workflows

- Add crop presets, collage layouts, batch processing, print layouts, traditional Lab color match, LUT/photo styles, photo frames, smart albums, and collections.
- Expand Live Photo / Motion Photo detection, pairing, preview, export/conversion, keyframe replacement, and metadata repair.
- Add Default, Retro, CMYK, Black hole, and Cyberpunk themes, including guarded idle effects for the two dynamic themes.
- Synchronize the main window's native maximize state independently of TitleBar timing and migrate legacy missing/invalid dynamic-theme intensity to Standard without overriding an explicit Off value.
- Clamp high-DPI photo capture/render buffers to WebGL texture and viewport limits. Black hole falls back to a CSS card spiral; Cyberpunk falls back to CSS displacement/color/RGB-edge glitch when capture, upload, or context retention fails.

## AI Plugin Host

- Keep signed packages, publisher trust, permission grants, bearer-token loopback auth, input staging, runtime conflict gates, and output adoption/discard as required boundaries.
- Show manifest-contributed actions such as SA-LUT only when the managed plugin is reachable.
- Broadcast plugin status changes across windows so start, stop, restart, and failure states update menus immediately.

## Packaging and Platform Scope

- Refresh the canonical application mark and regenerate Windows EXE/taskbar/tile icons plus Linux/shared PNG and in-app title/About/Welcome assets.
- Generate icons in a temporary directory and hash-sync changed files only, avoiding Windows user-mapped-file failures when unchanged PNGs are open.
- Support Windows x64/ARM64 and Linux x86_64/ARM64 only. Remove committed Android/iOS icon trees and macOS ICNS, Info.plist, native pasteboard bridge, and menu/bundle configuration.
- Remove obsolete scan/XMP wrappers and keep the EXIF fixture helper test-only so release builds remain warning-clean.
- Build Windows frontend assets from the repository root with `pnpm --dir src-vite build`, close running PicAiPic processes before packaging, and keep release plugin storage independent of the install directory.
- Treat same-version MSI replacement tests carefully: uninstall the existing package or bump the version; use NSIS for rapid local UI/theme retests to avoid Windows Installer cache reuse.

The 2026-07-30 Windows x64 clean build produced release EXE, NSIS, and MSI artifacts; administrative MSI extraction confirmed the current frontend chunks are embedded in the installed executable. Representative laptop testing of both primary WebGL paths and their CSS fallbacks remains part of release regression before promoting the private draft.
